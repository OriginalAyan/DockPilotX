Lattice VinaPilotX

Dock ligands with AutoDock Vina from ChimeraX. Open it from Tools → Binding Analysis → Lattice VinaPilotX or with vinax gui.

  1. Settings – browse to vina/vina.exe (or its folder) or press Download latest Vina; choose the working directory; switch the native .pdbqt opening override on/off.
  2. Inputs – the receptor opens in the scene when you select it (other models are hidden); ligands appear in a table with heavy atoms, torsions, dimensions (principal-axis extents), longest distance, charge, acceptors/polar H, folder and file. The largest ligand is highlighted to help size the box.
  3. Box – type center/size, build it from the selection, or drag it with the mouse.
  4. Run – set exhaustiveness etc. and press Run docking. Interrupted batches resume; finished ligands are not re-docked unless you tick the re-dock option.
  5. Results – sortable table; double-click to open poses (ViewDock). Export to CSV.

Working-directory layout

receptor/  ligands/  results/  logs/  vina_config.txt  summary.csv  manifest.json

Commands

vinax gui [settings|inputs|box|run|results]
vinax vina [path FILE] [download true]
vinax box center x,y,z size x,y,z
vinax box selection true padding 4 [method bounds|centroid]
vinax run receptor.pdbqt ligands C:/ligs   (a file, a folder, a library file, or a wildcard such as C:/ligs/*.pdbqt)
      workdir C:/docking/p1 \
      [center x,y,z size x,y,z] [exhaustiveness 8] [num_modes 9] [energy_range 3] [cpu 0] \
      [parallel 1] [seed 0] [scoring vina|vinardo] [overwrite true] [recursive true]
vinax cancel
vinax pdbqt [native true|false]

Seeds: with the default (random) Vina picks its own seed for each ligand; Lattice VinaPilotX reads the seed Vina reports and records it in the Results table, summary.csv, manifest.json and the log. Enter a number to force the same seed for every ligand.

Parallel jobs means separate ligands docked side by side, not several ligands docked into the site together.

Without center/size, dock uses the box in the scene.

Receptor and ligands must already be prepared PDBQT files (for example by Meeko or AutoDockTools). Full details: see DETAILS.md in the project repository.
